From AVC to a cloud run

  1. Download the notebook AVC creates. It contains the processing code and your settings.
  2. Upload the original recordings to a private Kaggle dataset, then attach it to the notebook.
  3. Enable Internet, choose an available GPU, then Save & Run All.
  4. Download learning-results.zip when finished. Return to AVC, choose the matching job and import it.

AVC does not upload or start the cloud run for you. Free compute has availability and usage limits. In Colab, keep the session connected and download results before it expires.

Speech and OCR can misread names, Taglish and equations. Visual notes contain selected frames, so review important details against the recording. Every result folder includes a source guide for AI-assisted learning.
